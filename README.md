# São João Vote

Sistema web de votação de camisas juninas.

## Tecnologias
- ASP.NET Core MVC
- PostgreSQL
- Entity Framework
- Railway

## Funcionalidades
- Ranking automático
- Votação em tempo real
- Persistência de votos
- Responsividade mobile

## Status
Projeto offline para reformulação e reutilização da infraestrutura em uma nova versão do sistema.
